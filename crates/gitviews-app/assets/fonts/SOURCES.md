# 内嵌字体来源

这些字体用于匹配 Pencil 设计中的 `Noto Sans SC` 和 `JetBrains Mono`。字体文件保持官方原始二进制内容，未做子集化或修改。下载日期：2026-10-29。

## Noto Sans SC

- 来源：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)。
- 原文件：[NotoSansSC[wght].ttf](https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf)，在此仅将文件名改为 `NotoSansSC-VF.ttf`。
- 字体内部版本：`Version 2.004-H2;hotconv 1.0.118;makeotfexe 2.5.65603`。
- 字体家族：`Noto Sans SC`；可变字体包含 100–900 字重，设计使用 400、500、600。
- 原始许可：[OFL.txt](https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt)，保存为 `OFL-NotoSansSC.txt`。
- Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.

## JetBrains Mono

- 来源：[JetBrains / JetBrainsMono v2.304](https://github.com/JetBrains/JetBrainsMono/tree/v2.304)。采用官方稳定发行标签，避免开发分支产生字重或字形变化。
- 原字体目录：[fonts/ttf](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf)。
- `JetBrainsMono-Regular.ttf`：400；`JetBrainsMono-Medium.ttf`：500；`JetBrainsMono-SemiBold.ttf`：600。
- 字体内部版本：`Version 2.304; ttfautohint (v1.8.4.7-5d5b)`；字体家族：`JetBrains Mono`。
- 原始许可：[OFL.txt](https://raw.githubusercontent.com/JetBrains/JetBrainsMono/v2.304/OFL.txt)，保存为 `OFL-JetBrainsMono.txt`。
- Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).
